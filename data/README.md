# Données de l'enquête

Aucun fichier de réponses individuelles n'est publié dans ce dossier pour le moment.

Les réponses sont stockées dans une feuille Google Sheets associée à l'application Apps Script. Avant tout partage ou ajout d'un export ici :

1. vérifier qu'aucun nom, e-mail, téléphone, commentaire libre ou identifiant indirect n'est présent ;
2. supprimer les lignes de test et documenter les exclusions ;
3. vérifier les effectifs et les variables avec le [dictionnaire](../documentation/dictionnaire-variables.md) ;
4. demander l'accord des personnes responsables du projet et respecter les consignes de l'enseignant ;
5. privilégier un tableau agrégé si les données individuelles ne sont pas nécessaires à la vérification du travail.

Ne pas déposer ici de lien privé Google Sheets, de jeton Apps Script, de mot de passe ou de donnée personnelle.

Pour l'instant, ce fichier documente la provenance et les précautions à prendre ; il ne prétend pas contenir le jeu de données final.
